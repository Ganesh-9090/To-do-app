# To-do List application

a simple console based to do list application built using python

## project Overview

this is a simple console-based To-Do list Appllication developed using python . The application helps users manage their daily life tasks efficiently by allowing them to add,view,and delete tasks. all tasks are stored in a text file ,ensuring data persistence even after the program is closed.

## objectives

-Learn Python fundamentals.
-understand files handling operations.
-Work with lists and string manipulation.
-develop a menu driven console application

## Features

-Add new tasks
-View all saved tasks
-Remove completed or unwanted tasks
-persistent storage using a text file
-user-friendly menu interface
